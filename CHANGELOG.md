# Aether — Changelog

## [0.1.0] - 2026-05-13

### Initial release
- Cross-platform support: Windows, macOS, Linux
- Game library with gallery and list views
- Search, filter (All / Installed / Downloaded / Updates / Favorites) and sort
- ADB device detection (USB + wireless)
- Installed app list with real game names
- Download manager with resume, retry, EWMA speed tracking and ETA
- Install pipeline with auto-reinstall on signature mismatch or version downgrade
- OBB support
- Save data backup and restore
- Metadata loader from public mirror (public.json + meta.7z)
- Contribution system: detect new apps and version updates, upload via rclone
- Settings: download path, bandwidth limit, proxy, auto-reinstall, adult content toggle
